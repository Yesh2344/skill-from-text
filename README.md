# Skill From Text

I built this project to make it easier to turn any text into a skill that can be loaded on demand. It started as a fork of [virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill) and has evolved to include new features and improvements.

## What it does
Skill From Text converts any text into a structured skill that can be loaded on demand. It supports a wide range of file formats, including PDF, EPUB, DOCX, and more.

## How to use it
To use Skill From Text, simply run the command `/skill-from-text your-text.pdf` (or any other supported file format). This will create a new skill in your skills directory that you can load on demand.

## What I changed
I made several changes to the original project, including:
* Improved support for multiple file formats
* Added a new feature to extract key terms and concepts from the text
* Enhanced the skill loading process to make it faster and more efficient

## Install
To install Skill From Text, run the command `pip install skill-from-text`.

To use Skill From Text, run the command `/skill-from-text your-text.pdf`. This will create a new skill in your skills directory that you can load on demand.
